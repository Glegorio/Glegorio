Sou estudante de **Análise e Desenvolvimento de Sistemas** na **FATEC de Franca**, técnico em **Desenvolvimento de Sistemas**, **Marketing** e **Programação de Jogos Digitais**.

Atualmente meu foco principal está no desenvolvimento de **aplicações desktop**, utilizando **C#**, **Windows Forms**, **.NET** e **bancos de dados relacionais**, especialmente **PostgreSQL**.
